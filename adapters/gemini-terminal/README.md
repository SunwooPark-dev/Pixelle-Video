# Gemini Terminal Starter Adapter

## Goal
Provide a terminal-first Gemini workflow starter for the local Pixelle-Video fork.

## Quick start
1. Start the stack:
   - `bash adapters/shared/start-pixelle.sh`
2. Confirm health:
   - `bash adapters/shared/start-pixelle.sh --health-only`
3. Feed `starter-prompt.md` into your Gemini terminal workflow as initial context

## Notes
- Work on the fork only
- Keep adapter work additive
- Use the shared helper scripts as the first entrypoint
