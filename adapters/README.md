# Adapter Starters

This directory contains additive starter adapters for three operator environments:

- Exact requested Phase 2A paths:
  - `codex/`
  - `antigravity/`
  - `gemini/`
- Expanded handoff/starter variants:
  - `codex-app/`
  - `antigravity-app/`
  - `gemini-terminal/`

Shared helpers live in `shared/`.

These files are meant to be **immediately usable starting points**, not finished integrations.
